# 🌿 Portfolio 3D Thiên Nhiên – Huỳnh Phúc Khánh Lộc

Trang web giới thiệu bản thân với giao diện **3D thiên nhiên** (rừng ánh sáng, đồi núi 3D, đom đóm & lá bay), được tạo bằng **Vibe Coding** ✨

- 👨‍🎓 Học sinh trường Nguyễn Đình Chiểu
- 🚀 CEO Gemini Center
- 🎧 Đang train về Vibe Coding

## Tính năng
- Màn hình mở đầu xuyên rừng đom đóm, tia nắng sớm và lá bay 3D kèm âm thanh chuông gió
- Nền 3D gồm đồi núi nhấp nhô, Cây Ánh Sáng 3D đung đưa theo gió, đom đóm phát sáng và lá bay xoay 3D
- Thẻ nghiêng 3D, khối lập phương kỹ năng kéo xoay được, thẻ dự án lật 3D
- Hiệu ứng xuất hiện khi cuộn, giao diện tương thích điện thoại

## Chạy thử
Mở file `index.html` bằng trình duyệt hoặc xem trực tiếp tại: https://klocevin-ai.github.io/portfolio-3d/

## Chỉnh sửa nội dung
Mọi thông tin nằm trong đối tượng `PROFILE` ở đầu file `script.js`.
