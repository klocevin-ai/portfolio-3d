## Tính năng
- Màn hình mở đầu "xuyên không gian" (warp) kèm âm thanh
- Nền quả cầu hạt 3D xoay theo chuột
- Thẻ nghiêng 3D, khối lập phương kỹ năng kéo xoay được, thẻ dự án lật 3D
- Hiệu ứng xuất hiện khi cuộn, giao diện tương thích điện thoại

## Chạy thử
Mở file `index.html` bằng trình duyệt. Không cần cài đặt gì thêm.
